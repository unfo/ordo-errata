# HOTFIX 14.1

## GAMEPLAY AND BALANCING TWEAKS

**Heroic Stalker Bolt Rifle**
- Number of body shots required to trigger auspex scan reduced from 4 to 3
- Auspex scan radius increased from 8 to 10 metres

**Heroic Combi-Flamer**
- Reduced charge up time for flamer barrel
- Bolter barrel damage increased by 10%
- Flamer barrel ammunition can now be replenished using the Ammo Crate.

**Heroic Combi-Melta**
- Melta barrel ammunition can now be replenished using the Ammo Crate again.

**Heroic Power Fist**
- Can now fire a melta blast after a single charge in hold stance.
- Melta blast attack after a delayed light attack damage has been slightly increased.

## CUSTOMISATION

- Minor customization fixes

## ENEMIES

**Scarab Occult Terminator Sorcerer**
- Delay for a followup double beam attack has been increased to accomodate for slower dodge roll animations
- Teleport ability now deals significantly reduced damage.

## GENERAL FIXES

- Fixed an issue with Battlefield Conditions "*Squad Unity" *and "*Split Up" *radiuses being mixed up.
- Fixed a bug with Tactical's Perk "*Kraken Penetrator Rounds" *granting penetration for projectile based weapons.
- Fixed a bug with Battlefield Condition "*Come Prepared"* not granting 10 stimms to all squad members.
- Fixed: Some Ordeals were not taking the players progress if they join a game that was already started on the first sector in Siege Mode.
- Fixed: Weekly Siege Mode ordeals progression was not counted in some cases.
- Fixed several issues with server side mods on Steam Workshop
- Crash fixes.
